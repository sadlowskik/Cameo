# Complete production issue checklist

Updated 2026-09-07 from a source, test, ledger, and retained-evidence audit. This
checklist covers all 61 issue IDs from `PRODUCTIZATION_PLAN.md` section 15.

States mean:

- `Implemented locally`: the described production path and its local acceptance
  fixtures pass. Release/environment qualification named in the remaining-evidence
  column is still required; this is not a certified release result.
- `Partial`: a tested production slice exists, but part of the issue's required
  implementation is still absent.
- `Unverified as complete`: useful primitives exist, but no end-to-end acceptance
  case establishes the roadmap deliverable.
- `Open blocker`: an incomplete production path blocks downstream qualification.
- `Blocked`: the issue cannot close until its dependencies close.

Current accounting is 6 implemented locally, 47 partial, 7 unverified as complete,
0 open production blockers, 1 blocked release candidate, and 0 release-accepted.
The previous checklist's generic "Open acceptance" labels hid these implemented
slices; they did not mean that all underlying work was absent.

passed 293 test results; Knossos `cargo test --all-targets --locked` passed 568;

`node scripts/render-capabilities.mjs --check` verified all 17 manifest entries.
